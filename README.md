# ExploreMzansi
Exploring alignment elements further

Aligning Elements:
1. display flex/../ -> as soon as you apply display: flex, the children will stop stacking vertically like normal block elements and will automatically line up side-by-side in a horizontal row.
2. flex direction -> This property defines the Main Axis(row). It decides whether your items line up horizontally or vertically.
3. justify content -> This property aligns and distributes items along the Main Axis. Because the Main Axis changes based on your flex-direction, justify-content controls horizontal spacing when using row, and vertical spacing when using column.
4. align items -> This property aligns items along the Cross Axis. Think of it as the counterpart to justify-content. If flex-direction: row, align-items controls how items line up vertically up and down.
